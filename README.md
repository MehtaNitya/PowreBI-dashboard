📊 Power BI Dashboard Project
📌 Project Overview

This project is an interactive Power BI dashboard designed to analyze and visualize data effectively using charts, KPIs, and filters.
The dashboard helps users gain insights, identify trends, and support data-driven decision-making.

🎯 Objectives

Build an interactive and user-friendly dashboard

Interactive charts and graphs
